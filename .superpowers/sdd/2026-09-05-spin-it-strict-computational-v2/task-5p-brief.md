## Required geometry construction

Inputs are actual nonoverlapping dyadic Full cuboids, not adaptive leaf bounding cells. Source max depth D<=20. Implement deterministic sparse shared-face overlay:

1. Each primitive contributes six square faces. Group by normal axis and exact integer plane on source depth-D lattice. Project to cyclic coordinates u=(axis+1)%3, v=(axis+2)%3. Every face is an aligned dyadic square.
2. Per plane, insert face-square paths into a sparse quadtree rooted at the root square. Each node records the primitive on the negative side (upper face, outward +axis) and positive side (lower face, outward -axis), with ancestor ownership inherited during traversal. Two different primitives on the same side are invalid overlap. Never scan every primitive against every other one; O(D*input faces + output) construction with checked node budget. Empty uncovered quadrants produce no patch. Descend only paths present or needed to tile an inherited face; resulting atomic square patches have exactly one owner on each occupied side and at least one occupied side.
3. Atomic patch corners across ALL planes define shared edge breakpoints. Account for hanging vertices from perpendicular faces too, not only opposite coplanar patches. Gather every material point into axis-line dictionaries keyed by the other two coordinates; take sorted point ranges on each patch edge. No O(points*edges) search or global finest-grid expansion.
4. Give each patch ONE shared center and triangulate its rectangular boundary polygon (including all collinear edge breakpoints) as a center fan. Canonical direction is +axis; negative-side owner uses +orientation, positive-side owner the reversed orientation. Common patch triangles/vertex IDs are stored once and referenced by both primitive boundaries, never triangulated independently per owner. This fixes the coarse/fine shared-face mismatch from Task5o's exact counterexample.
5. Use integer material keys at lattice D+1 so patch centers are exact dyadic keys. Generate coordinates by canonical FMA root planes. Require represented spacing at D+1 > maximum root endpoint ULP, as a sufficient guard against collapsed center/edge coordinates; unsupported frames reject explicitly, no clamping, snapping, coarsening or perturbation. All rest triangles must have finite distinct vertices and nonzero oriented area; no silently omitted degenerate faces.
6. Each primitive boundary must be closed and consistently oriented as an indexed triangulation: every undirected edge occurs exactly twice with opposite direction. Every shared triangle reference must be oppositely oriented and every actual material face area covered exactly once on each owning side. Store enough patch metadata (axis, plane, tile level/UV coordinates, owner IDs, triangle range) for independent coverage auditing, not only a passed boolean. Use a noOwner sentinel for an absent side.
7. Primitive boundary closure/shared indexing does not establish global material manifoldness at edge-only contacts, prevent self-intersection after deformation, or enforce shell thickness. Keep those future geometry gates explicit. A source surface cage or material oracle may reject singular input earlier; no fallback repair.
