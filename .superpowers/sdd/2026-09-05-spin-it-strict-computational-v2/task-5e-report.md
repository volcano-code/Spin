## Implementation

Added immutable `verification::ExactCuboidUnion` with validated implementation-default input/output/intermediate guards. The factory extends the existing opaque rational Nef implementation through one narrowly scoped friend, and does not expose mutable CGAL state. It constructs actual exact box solids, applies a depth-first balanced finite regular-closed union, checks each explicit new operation, rejects nonsimple edge/point contacts, and converts the resulting exact boundary using the pinned CGAL hole-aware constrained triangulation. It exports all bounded-volume shells, including negative void boundaries, and requires each rational coordinate to round-trip exactly through its binary64 export. Nonrepresentable coordinates produce `NONREPRESENTABLE_GEOMETRY`, never a lossy accepted mesh. Valid orthogonal binary64 box unions normally need only input endpoint coordinates; no artificial nonrepresentable fixture or perturbation was introduced to force this defensive branch.

Canonical generated output sorts finite vertices lexicographically, normalizes generated signed zero, rotates each triangle without changing its orientation and sorts faces. The signed triangle-region auditor rejects degeneracy, unreferenced vertices, inconsistent winding, nonmanifold vertices/edges, intersections and invalid nesting. A subsequent unregularized exact symmetric difference establishes inclusive equality to the original Nef union; volume/moment equality is not used as a substitute. Empty input is a valid explicit empty algebra operand, not physical-object or optimizer success. Ordered original boxes, settings, pinned backend identity, exact gate outcomes, mesh hashes and explicit resource counts bind the product digest.

Added `spin2014::SourceMaterialBoundary` and its result/settings interfaces. Construction accepts an actual `SourceAdaptiveDomain`, finite exact binary beta and one density, and calls the existing `sourceBinaryCuboids` with canonical `SourceSurfaceOctree::cellBounds`. There is no arbitrary cuboid/source-hash/solver-passed injection API. It preserves original outer V/F byte-for-byte and appends the complement orientation of the signed union boundary: union roots become inward cavities, while union void boundaries become outward retained islands. Original holes remain original boundary components. Both cavity and combined final V/F are owned immutable copies.

The product records source/partition/binary identities, original/design/final/carved exact region and boundary facts, independently computed inclusive partition `{final,newly carved}=original` with disjoint interiors, and carved-subset-original-design evidence. These exact facts preserve fixed material `original outer minus original design`; it is not redefined using accepted source volume or guessed density. The exact clearance check measures original boundary to newly carved boundary, retains rational squared distance and witness faces, requires strict noncontact for nonempty carving, and accepts threshold equality. Empty carving records not-applicable clearance with no fabricated distance. It does not certify all-pairs cavity webs, feature size, access or manufacturability.

Final geometry is independently reintegrated by `computeSurfaceMassMoments` (signed tetrahedra), compared in all ten components to density times original Algorithm1 outer moments minus selected source-cell moments, using the fixed root-side powers 3/4/5 and normalized threshold `1e-10`. Positive finite mass and central inertia PSD within `128*epsilon*density*side^5` are mandatory. Both moment vectors, all normalized residuals, the minimum inertia eigenvalue and mesh identities are retained. No caller-supplied expected mass vector grants acceptance.

Added `solveSourceAdaptiveSpinMaterial`. The existing source runner's unchanged body is factored into one private endpoint shared with the original public runner. Only its internally generated `BinaryMomentValidated` outcome moves its actual terminal `SourceAdaptiveDomain` and exact binary vector into the wrapper. The wrapper never reconstructs a partition from public mutable result leaves/status/hashes and never accepts external success JSON. The original runner calls the same body without requesting a terminal handoff. There is no numerical retuning, extra solve, geometry-repair optimization, changed objective/default/rounding or changed legacy output hashing. The wrapper always validates/hashes boundary settings before solving, uses exactly `request.density`, keeps numerical and geometry outcomes separate, and binds request/complete trace/output/terminal partition/material checks into its own digest.

## Resource accounting boundary and concerns

Defaults are `maximumInputCuboids=10000`, `maximumOutputVertices=1000000`, `maximumOutputTriangles=2000000`, `maximumIntermediateComplexity=4000000`, all explicitly implementation defaults. Intermediate counts are the actual sum of vertices, halfedges, halffacets and volumes of the live explicit new union/regularity/roundtrip Nef operands/results, including the post-import region solid. Conservative operation-work preflights and post-operation observations fail with diagnostics and no accepted partial mesh. Balanced reduction avoids retaining all individual Nefs. Mesh triangulation size is counted from actual polygon cycles (`n+2h-2` per facet), so exact output-cap equality is accepted; a loose triangle estimate is not used as an output rejection criterion. Final V/F caps apply to the **combined original outer plus cavity boundary**, not only the cavity mesh. Tests cover exact combined equality and one-below failures independently for vertices and triangles.

CGAL internal allocator temporaries are likewise not an allocator or aggregate cgroup cap. No universal observation of all auditor allocations is claimed. Controller explicitly directed retaining this bounded scope, avoiding a guessed auditor-work preflight or broad auditor restructuring absent a concrete failing budget case. This limitation remains for independent review against the brief.
