densities, scale, axis, target origin and wall setting. Changes the application
from yo-yo to the separately defined pure-height top endpoint. Feasibility and

PCG64 Gaussian dual coefficients on indices0,1,2,3,7,8 from seed0 or1, converts
to native coefficients and normalizes. All generated attempts are retained.

actual per-trial source/Boolean/directional ledger plumbing, not convergence.

60 evaluations/attempt, grid8, initial radius4, max4 radius doublings, existing
raw1e-12 and material1e-6 thresholds. No answer-based start selection, omitted
failed seeds or mid-run grid changes. Fixed-grid source is not paper fixed-normal
source; that algorithm requirement remains open.
