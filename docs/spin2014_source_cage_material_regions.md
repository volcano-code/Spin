## Exact chain and represented design

The outer, signed carved and signed material boundary are converted to exact regular-closed regions. Carved absence uses an explicit-empty operand with no invented empty boundary audit. Native region and boundary facts preserve signed-shell nesting, orientation, connected material components and bounded void components. The backend may reverse a checker-only negative shell when building a solid; the immutable original mesh is untouched.

The first exact partition requires outer = material union carved, inclusive set equality, pairwise interior disjointness, no missing/excess content, and each part a subset of outer. Incomplete facts never pass.

The represented design D is defined as the union of all Full primitives in the immutable terminal SourceCageBinding. For each selected primitive, the implementation extracts its actual deformed conforming surface in original reference order with the stored orientation. The compact vertex order is ascending original point ID. Each witness retains primitive index, binary beta owner, source key, mesh digest, exact region facts and an explicit subset-of-outer relation. The primitive is selected only when its actual immutable binary beta equals one.

A second exact partition establishes the constructive proof:

`C = union(selected immutable Full primitives) subset D`.

D is the represented terminal design, not the continuous author design or rest geometry. There is no invented global design mesh or hash. For selectedCount = 0, the witness list remains empty and the second partition uses one explicit-empty algebra operand.

The full actual binary functional is evaluated in value-only mode to obtain deformed primitive points. Its output digest must equal Task5y's binaryFunctionalOutputSha256. Source, functional, binding, partition, binary state and emitted output identities are retained; functional, partition, binary state and emitted meshes are independently hashed and checked against the immutable upstream audit.

Finally the native exact triangle-boundary distance checks outer versus carved. minimumOuterWall is a finite nonnegative binary64 in model units, converted exactly to a rational. A nonempty cavity must have applicable = true, contact = false and atLeastMinimum = true, including threshold zero. An empty cavity must produce actual NOT_APPLICABLE with absent contact, distance, witness and threshold-result facts. Exact squared rational distance and witness face IDs are preserved.

This only measures outer-to-carved separation. Inner webs, features on the same component and complete manufacturing thickness remain NOT_ESTABLISHED.

## Bounds and failure evidence

All exact algebra uses one invocation-local mutable ExactNefBudget. Region operands and live budget contexts never escape. Only a copied final budget snapshot escapes, after local regions release their leases. This bounds explicit application Nef complexity, not opaque CGAL allocations or process RSS.

Settings cap the selected primitive witness count, aggregate planned points and triangles, known owned buffers, estimated exact diagnostics and maximum Nef complexity. The primitive cap applies to selected witnesses, not every unselected binding primitive. Count multiplication/addition and native index limits are checked before size-dependent evaluation, mesh, evidence-list or exact-region allocation. Conservative point counts use three vertices per selected face before deduplication. Diagnostic planning includes worst-case retained face pairs, shell diagnostics, nesting and partition witnesses with a capacity allowance. Native rational/CGAL allocator internals remain under the external 24 GiB virtual-memory / 60-minute guard. Existing upstream value-only BBW and shape budgets remain in force.

A deterministic scientific hash covers outcome, settings identity, all input identities, selected witnesses, raw exact facts, reason and the final Nef budget snapshot; it excludes time and pointer addresses.
