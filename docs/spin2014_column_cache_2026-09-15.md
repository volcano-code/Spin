# Spin-It 2014：单次 QP 列缓存实现与验证

## 结论

已实现并验证本次批准工作的第一项：在一次 `solvePrimalBoxQp` 内复用不变的
逆 L-BFGS 度量列。没有改变输入、目标、容差、舍入、矩阵乘法顺序或工作集规则。
解析/耦合夹具和完整 G6 茶壶的科学输出保持一致，但 G7O7 仍在 300 秒超时。
这不是论文案例完成，也没有解决二值材料残差。恢复接口尚未实现。

主项目及其他既有修改没有覆盖；未创建提交或标签。

## 变更与边界

- `src/spin2014/SlqpTangentQp.cpp`：固定等式列首次计算后复用；保留仍在工作集
  内的面列，释放面先移除，重新进入时重新计算。缓存只存在于单次调用。
- 存储随当前等式及活动面数量增长，不保存所有历史访问面，也不展开完整 Hessian。
  它额外保存当前列的副本，不宣称总内存降低。
- Phase I、Schur 矩阵形成/分解、原始 KKT/盒约束判定及步长检查保持原实现。
- `tests/spin_it_2014_column_cache.cpp`：GNU 链接包装仅计数，所有计算调用真正的
  `applyInverse`；未替换结果、未增加生产测试开关。CMake 在 Linux GNU/Clang
  下注册该测试；不把该 ABI 专用计数测试宣称为跨平台验证。
- 旧二进制和源码快照保留。旧运行的当前源码绑定自动变为 `STALE_RESULT`；
  本轮只对其历史科学内容做比较，不改写旧 provenance。
