# Spin-It 2014：固定 primal V2 下的分辨率与终止位置对照

## 范围与协议

本轮只运行已实现算法的受控对照，不改 C++/Python 求解器，不改变外形、姿态、
轴、设计域、壳厚、gamma、初始化、舍入规则或验收门。全部为同一重建茶壶，
不计入作者原始案例，不宣称 level-9 或完整论文复现。

项目目录：`/data/xvxinyao/moment-guided-spin-v1/code/make-it-balance-paper-sim`。
基线与冻结模块位于 `build/spin2014-primal-box-20260915`。
本轮三个目录前缀为 `build/spin2014-primal-resolution-20260915-`，后缀分别为
`g6o6-terminal`、`g7o6-paper`、`g7o7-paper`。

G 为源表面八叉树采样上限，O 为优化分区允许层级。全部从同一 OBJ 表面
重新构造源数据，不读取低分辨率 occupancy 做插值。允许 O=7 不自动等于
真实优化到 level 7；实际求解分区和终止后生成的分区分开报告。

三个 `PROTOCOL.md` 与配置在新实验开始前写入，各计划两个独立运行。
机械配置比较确认：terminal 只相对基线改终止策略；G7O6 只改源采样深度；
G7O7 只相对 G7O6 改优化深度。配置继承的历史 scope 字符串不作为案例身份；
本报告、目录与协议明确标注本次分辨率实验。

统一使用 FINITE_BOX_PRIMAL_V2 模块 SHA-256：
`56355966dc78e0ef3f5ed0ba0257dee213cc0bd80f6f5659afe22a656eb2b1bd`。
source observation 在每次运行前后核验；源码、模块与旧证据未被覆盖。
资源门：单线程 OMP/BLAS、24 GiB 地址空间、300 秒墙钟、12 个自适应阶段、
每阶段 960 次迭代、12000 叶单元，运行顺序执行。资源触发后保留失败，
其第二次计划身份仍保留为未完成，不扩预算或降分辨率冒充正式结果。
运行前 /data 可用空间约 1.3 TiB。

G7O6 的源采样实际访问 level 7，源统计记录了第 7 层 25920 个节点。
末态 916 个单元中，816 个 level-6 单元在舍入时改变材料贡献；
本次较粗层舍入贡献为零。误差依然主要表现为横向一阶矩 X。
终止后分区与末次求解分区不同，terminal_relaxation_kkt_applies=false。
源采样加密改变离散设计域与最优路径，误差不必单调下降，不能推广为任意模型结论。

## 检查证据

使用系统化排错流程拆开变量，代码图谱辅助定位入口，最终以当前源码及实际
轨迹为准。37 项阶段/舍入/在线记录/原生策略测试与 78 项来源/方向 replay
测试实际通过；这是专项检查，非全仓库发布门。求解器未在本轮重编译。

各目录的 verification.json 自动核对有效源码观察集合、实际模块、构建配置、
输入、完整输出及重复运行，stage-audit-1/2.json 完整耗尽归档并重算各层舍入贡献。
没有接受手填 passed 标志来升级论文、几何或物理状态。

G6O6 terminal：两次归档 278 事件一致，每次 257 个接受更新；
独立 QP KKT 最大误差 8.06473e-15，下一状态误差零。
G7O6：两次归档 152 事件一致，每次 133 个接受更新；
独立 QP KKT 最大误差 6.71021e-15，下一状态误差零。
这不检查每个 QP 的中间工作集选择，也不证明非线性全局最优。

G6O6 terminal 两次运行器耗时约 32.77 / 31.99 秒；G7O6 约 34.33 / 34.35 秒。
两个配置的 stage-audit-1/2.json 也逐字节相同。

G7O7 首次运行墙钟 300.01 秒，exit=124；用户 CPU 297.35 秒、系统 CPU
0.24 秒，峰值 RSS 335996 KiB，无 swap。因此触发的是时间门，不是内存门。
保留约 416 MiB、11 个分阶段迭代文件及输入 provenance，没有完整 header、
summary 或带完成校验的 JSONL 归档。文件数量不能用来宣称已收敛阶段数，
也不能仅凭配置 O=7 宣称已完成 level-7 验证。
这些是保留的局部记录，**尚不是已验证可恢复的断点**，不可伪称可以直接续跑。
attempts.json 保留两个计划身份和外部资源状态，没有将 UNKNOWN 改成不可行。
输入/源码/二进制来源仍可单独核查，来源有效不意味着该次科学结果完整。
