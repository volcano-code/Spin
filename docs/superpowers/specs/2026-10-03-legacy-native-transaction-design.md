日期：2026-10-03。状态：设计方向已获确认；本书面设计待审核。

## 1. 目的与授权边界

为现有 Faster 原生求解器增加可选 `LEGACY_NATIVE_NORMALIZED_V1`
预测／事务入口，验证预测接口、认证、回滚和成本账本的工程正确性。
复用现有 Newton 循环，不创建第二套优化器，不修改严格 DUAL 入口。
本扩展不属于论文原算法完成证据，也不代表学习模型合格或获得加速。

用户已确认独立 LEGACY 入口、原循环复用、暂算与认证状态分离、失败
完整回滚而成本不回滚、先单步后最多三步的设计方向。本轮只编写设计，
不执行原生面板、不训练、不查询教师生成标签、不运行加速比较、不外发消息。
书面设计审核后再细化实现计划及执行方式。

只修改现有独立工作树，保留所有用户改动、历史构建、失败和冻结输入。
不覆盖原运行库，不将旧结果通过增加字段升级为新实现通过。

## 2. 已核对的实现与输入事实

- `include/spin/QuadricHollowingSolver.h` 已有真实求值接口、事件和结果；
  没有可恢复的原生预测事务 API。
- `src/spin/QuadricHollowingSolver.cpp` 的 `NewtonState` 及
  `solveSpinMomentSystemImpl` 局部保存状态、重启和线搜索游标；应在这里
  建立事务边界，而不是在 Python 用字典复制模拟回滚。
- `python/make_it_stand/spin.py` 的 external evaluator 与原生绑定均限制

- 外部交接包八条记录没有完整检查点、乘子、状态版本和线搜索／重启游标。
  它们仅是开发缓存输入，不可恢复成历史认证状态。
- 图谱最后更新于 2026-10-01，仅辅助定位；上述结论以当前源码为准。

## 3. 方案选择

| 方案 | 结论 |
| --- | --- |
| 放宽现有严格 external evaluator 的 profile 检查 | 拒绝：混淆操作方向矩阵与数学 Jacobian，破坏 DUAL 契约 |
| 独立实现预测版 Newton 或 Python 层回滚 | 拒绝：分叉线搜索／预算逻辑，不能恢复原生缓存和游标 |
| 独立 LEGACY 入口，内部复用原循环和真实几何入口 | 采用：扩展可显式关闭；所有默认路径保留 |

不做无关代码重构。只将事务所需的局部状态收拢为明确的内部状态对象；
原入口不提供 hook 时，保持原求值次序、接受规则、终止规则和科学输出。

## 4. 接口与身份契约

新增入口暂定名 `solve_spin_it_faster_legacy_transactional`，只接受 LEGACY
请求、实际几何求值配置、可选同步 predictor 及版本化事务设置。
固定材料由实际几何积分；不新增允许调用者手填不可核验固定矩的捷径。
旧接口不改变签名、默认 profile 或返回格式。新附件由已有运行证据系统绑定。

预测请求至少包含：

- `schema_version`、请求／输入几何／求值器配置摘要、坐标及单位约定；
- 当前原生归一化系数 q（十项及顺序）、目标坐标、材料密度；
- profile、预测器来源身份、认证 checkpoint 摘要、状态版本；
- 本次事务号、暂算步号，以及所依赖的上一暂算状态摘要。

认证 checkpoint 和当前 tentative state 不能共用一个含糊的 hash。
输入设计域身份在调用前已知；输出材料 geometry hash 只能由真实求值产生。
预测器不能通过填写 geometry hash 自行授予几何认证。

预测响应包含 `variable_moments[10]`、
`operational_direction_matrix[10,10]`、validity、source identity 和 timing。
可变矩是目标坐标下、已按可变材料密度计算的质量矩，不包含固定材料。
固定矩由原生适配器按原约定加一次。操作矩阵明确不是响应的数学导数；
不得改名后接入 DUAL Jacobian 路径，也不得从这项工程测试得出导数正确。

响应检查包括形状、有限性、profile、坐标／密度、输入与状态身份及支持域。
缺失、过期、越界、非有限或异常响应均进入真实回退，原异常类型和诊断保留。
硬中断、作业超时及内存限制终止整个作业，不能被普通预测异常处理吞掉。

## 5. 原生状态与提交协议

将可回滚数值状态与不可回滚成本状态分开。检查点仅由真实求值成功后建立；
首版检查点是当前进程内部的原生状态，持久化附件只供审计，不承诺跨进程续算。
不得从交接缓存 q 和矩重新拼出一个声称历史真实的检查点。

可回滚状态包括 q、乘子、残差、方向及缩放、线搜索控制游标、重启控制位置、
材料映射、几何／拓扑／导数缓存、认证标记及科学轨迹的认证前缀。
缓存使用不可变值或分代隔离，禁止暂算写入共享的认证缓存。
外部 predictor 的副作用不纳入回滚，因此仅支持声明为纯函数的同步回调；
其输出身份与异常仍由运行器记录。不可撤回的外部副作用不受支持。

状态转换：

1. 用原真实入口初始化、筛选并得到认证状态。
2. 从认证状态开始事务；用有效预测响应执行原有线性化和试探规则，
   但事件标为 tentative，不把残差、拓扑或停止判定当作真实通过。
3. 单步阶段每个暂算步后真实检查；后续最多三步阶段可暂存至多三个
   接受步。收敛迹象、错误、预算边界或分支不确定立即结束暂算并校正。
4. 提交前对暂算链上每个待认证状态调用真实求值，重新计算乘子、残差、
   有效导数、几何和拓扑，并按原规则逐步验证真实残差下降与合法性。
   不以仅检查块末端代替中间必要检查，不复用预测给出的拓扑认证。
5. 所有待认证步通过才原子提交整块；下一步从真实末态重新线性化，
   不沿用预测操作矩阵。真实停止与最终材料验收仍调用原路径。
6. 任一步失败则整块丢弃，恢复最后认证状态，记录回滚后执行原真实步骤。
   两个连续失败块后，本次求解禁用预测；成功认证块将连续失败数清零。

操作矩阵可改变暂算方向，因此一般预测运行不承诺与全真实轨迹逐位相同。
全真实透传／hook 关闭必须与匹配的 LEGACY 基线一致。预测方向不得被标为
论文精确 Newton 方向；通过真实校正也不授予原论文算法等价或加速声明。

跨拓扑或封口变化必须用当前状态的真实几何和有效导数认证，不能使用旧
Jacobian。若中间暂算分支无法可靠认证，整块失败并回退；不能跳过该状态。

## 6. 预算和失败处理

保留请求原先的线搜索、重启、停止容差与每次尝试预算，不套用另一 profile
的默认值。暂算试探占用逻辑试探预算；每次真实调用也占用真实求值预算。
预算不因回滚归还，重启总次数亦单调增长。控制游标恢复不等于删除已经
发生的尝试：恢复后使用剩余预算，耗尽则如实返回资源终止，不强行再走一步。

每个事务记录 checkpoint、试探／校正调用、接受或失败原因、回滚、禁用状态。
失败输出只携带最后认证状态，不导出暂算几何作为最终成果。
终点仍执行原真实材料、互补材料和独立验收；制造门未知时仍为未知。

成本账本只追加：冷启动、加载／编码、可替代响应、必要几何检查、预测、
校正、回退、最终验收、异常与资源终止。所有事件具有父子 ID 和单调序号。
总时间使用根调用墙钟，分类使用互斥区间／exclusive 时间，不把父子时长相加。
预测器自报 timing 与宿主实测分别保留。时间不进入科学确定性摘要。

首次实现不减少必要真实检查次数；可能没有速度收益。交接包的历史 1.88 倍
上界不当作新结果，2 倍指标仍为未测；若必要成本证明上界不足，不通过减少
检查频率或改变验收换取速度。

成本比较必须分别列出 hook 关闭全真实基线、全真实透传工程对照、实际预测
运行，不能将透传引入的重复工作算作原基线。逐项记录基线接受状态求值、
被拒绝的线搜索试探、必要几何检查、暂算后逐状态认证和失败回退的调用数及
互斥耗时。一次真实调用同时提供矩与几何时用同一调用 ID 引用，不重复收费。
三步暂算仍需逐状态认证，不能引用“三步只有一次真实查询”的成本比例。
可节省预算只包括当前策略确实避免的计算；预测／编码即使假设零成本，必要
认证和实际失败回退成本仍须保留。只有同口径数据充分时才估算乐观上界；
不足则标为未测，上界不足 2 倍则报告该策略未达加速目标。

## 7. 测试、面板准入与证据

先做不使用交接面板的单元和小规模集成测试，再允许冻结的工程面板。

| 检查 | 必须能拒绝／证明的情况 |
| --- | --- |
| profile 隔离 | LEGACY 操作矩阵不能进入严格 DUAL；hook 关闭保持原行为 |
| 身份与密度 | 错误 q／状态版本／输入、重复加固定矩、重复乘密度均被检出 |
| 单步事务 | 有效透传提交；错误、非有限、异常、真实检查失败完整回滚 |
| 三步事务 | 中间失败丢弃整块；缓存无泄漏；两块连续失败后禁用 |
| 状态恢复 | q、乘子、方向、游标和缓存恢复；成本、失败和预算不减少 |
| 几何与停止 | 暂算收敛不授予真实收敛；分支变化不复用旧认证 |
| 证据 | 缺失事件／成本、单次运行冒充确定性、旧二进制和失配检查点被拒绝 |

原生接口构建、真实初始化以及 panel 到请求的身份映射全部通过后，才能运行
八状态面板。每条冻结状态最多一次真实透传、一次已指定故障，共 16 次。
使用共享、耐久、先预留后执行的预算账本；崩溃／失败预留也算已开始，不能
无记录重试。不改原 panel、不替换失败状态、不由误差选择新的输入。

八条缓存缺少原生状态，必须先确认其来源足以构造冻结请求，并以真实初始化
建立新检查点；不足则该条保持阻塞，不消耗一次虚构的“续算验收”。
单元测试不伪装成面板记录；独立重复使用另外预登记的小型方法夹具，不超过
这 16 次面板额度。成功路径在两个独立进程比较科学事件与材料身份，计时排除。

复用 `PaperRunEvidenceV2` 和现有封存／检查器附件。绑定有效源码、实际构建、
加载模块、教师 profile、预测器身份、请求、初值、完整账本及最终真实材料。
既有构建回执只证明其已支持的来源范围，不夸大为全工具链真实性证明。

## 8. 文件责任与实施顺序

- 原生接口及内部状态：`QuadricHollowingSolver.h/.cpp`；保持同一 Newton 内核。
- 几何与固定材料：复用 `QuadricMomentEvaluator` 和请求构造，不新写积分器。
- Python／pybind：新命名入口与版本化附件；旧严格接口不变。
- 测试与证据：在现有测试和运行证据体系注册，不建立平行审计系统。
- 冻结面板与上游模型：只读，不训练、不生成标签、不修改数据划分。

实现依赖顺序：基线负例与 profile 隔离 → 状态封装及 hook 关闭等价 → 单步
事务和真实验收 → 预算／成本反向测试 → 最多三步 → 原生面板准入 → 有限工程
运行及独立小夹具重复。正式实现计划在本设计审核后写出。

编译最多四并发，大型作业顺序；单作业 24 GiB、swap 0、60 分钟，数值库
单线程；运行中可用空间低于 20 GiB 安全停止。先测受影响模块，不重复已有
完整成功科学实验。源码变更影响公共路径时补相应 Spin-It／Faster 回归。

## 9. 完成与非完成声明

本子任务完成意味着兼容入口、原生事务、真实回退、账本和限定工程验证通过。
它不意味着有合格学习模型、获得 2 倍加速、完成 40 组合五轮比较、获得原始
论文案例，或关闭 Faster 的曲面／CAD／制造等独立阻塞。

后续若需要学习训练、放宽真实检查范围、扩大面板预算或改变搜索算法，均
作为新任务审核，不隐含在此设计中。两篇论文的最终目标与既有数值门槛不变。
