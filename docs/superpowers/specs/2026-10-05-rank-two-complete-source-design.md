## 1. 目标与边界

在现有 `triangulateQuadric` → source motion → 实际 Cherchi Boolean → 离散质量矩接口中，增加一个显式 opt-in 的完整、正则秩二抛物面源构造。补上有限法向片缺失的理想方向邻域、面内隐藏闭环、孔洞和多个分量，而不是继续增加一维边根统计。

本设计的交付分三层，不能互相替代：

1. **完整源构造**：固定法向网格与原截断球内，所有曲面片和正侧封口都有可复查来源，形成合法闭合网格。
2. **真实定类型导数**：新增顶点与 Boolean 交点的运动对应同一实际有限映射，返回真实 `10×8` 参数基及材料导数。
3. **调用集成**：保存实际材料、独立积分和失败事件；通用 Eq.14 所需的其他方向仍单独验收。

不修改目标、材料密度、姿态、原始半径、法向网格、Newton 残差或失败分母。低维导数不能填成十维；几何或导数失败不是不可行证书。

本文件不重做已接通的二维账本、五类应用分派、浮体 A→B、CAD 适配或逐论文审计。近锥面 CAD、作者原始案例、完整壁厚、仿真和 Spin-It 未完成项保留在总计划中，不由本设计授予通过。

## 3. 输入身份与精确秩

### 3.1 唯一几何权威

新路径使用经过构造器核验的 `PreparedRankTwoSource` 附件：十个**精确有理齐次系数**、系数顺序／交叉项约定、坐标与单位、规范化数值视图及其来源摘要。沿用现有系数顺序，二次交叉项在 `A` 的两个对称位置出现，因此多项式交叉项为 `2a_ij x_i x_j`。

附件只可由同一个工厂创建，不允许调用方拼接一份有理多项式与另一份近似相等的归一化向量。工厂保存原系数摘要、正尺度归一化算法版本、生成数值视图摘要与误差界；所有几何、根、导数和材料读取同一权威多项式。数值视图不是第二个几何输入，也不能用其 `evaluate/gradient` 偷换精确源几何判据。齐次规范化只允许正尺度，不能把 `q>0` 的材料侧翻转。

兼容现有 `QuadricCoefficients10` 的入口可以将实际存储的 binary64 值精确转为有理数；只有**这些实际值**满足精确秩二时才准入。不得用特征值阈值把一个真实满秩多项式投影为秩二。`fromUnnormalized` 的浮点逐项归一化不能充当精确秩证明。

新接口的齐次多项式无需把有理系数变为单位有理向量。归一化用于参数基和求解数值视图，正尺度不改变权威几何。原八个状态使用已保存 native 系数的精确 binary64 有理值，不换用显示上接近但不同的十进制多项式。

### 3.2 准入条件

令 `q(x)=xᵀAx+bᵀx+c`，必须认证：

- `A=Aᵀ`、`rank(A)=2`，存在非零核向量 `u` 且 `uᵀb≠0`。
- 输入、半径、法向网格与设计域摘要完整；半径 `R` 正且固定。
- 法向球三角网格为闭合、定向且无重叠的射线分区；每个法向三角形的三个向量线性无关。
- 设计域的完整三角形／实体位于截断球内部，并留有既定隔离余量。顶点半径上界可作为三角网格的保守包含证书；不是任意 CAD 曲面的顶点采样证书。

不满足时返回明确输入／表示状态，不进入求解。`rank(A)<2`、`uᵀb=0`、一般锥面和柱面仍由各自路径处理，不能在这里假装是正则抛物面。

## 4. 不依赖特征向量的图坐标

从 `adj(A)` 的非零列建立有理核向量，采用确定性的主元选择与齐次尺度。选择的主元、符号及所有比较结果进入分支身份。在该局部分支中，令 `u_k=±1`，并定向为 `β=uᵀb>0`。

对另外两个坐标 `i,j`，取：

`E=[e_i−(u_i/u_k)e_k, e_j−(u_j/u_k)e_k]`，因而 `Eᵀu=0`。

定义：

`h(v)=−q(Ev)/β`，`X(v)=Ev+u h(v)`，`G(v)=2AEv+b`。

这些恒等式由精确代数检查：`q(X(v))=0`、`∇q(X(v))=G(v)`、`uᵀG(v)=β`。该图覆盖整个正则抛物面；不需要非零曲率的两个特征值互异。

固定法向面 `N=[n0 n1 n2]` 的逆像为：

`P_N={v : N⁻¹G(v)≥0}`。

这是三个半平面的交，可以无界或为空。法向的长度不影响锥面分区；使用实际保存向量的精确值，不再次独立归一化而改变射线。理想法向不产生假的有限顶点；有限球内部分由后续完整分区直接给出。

球内条件为四次多项式：

`F(v)=vᵀEᵀEv+||u||² h(v)²−R²≤0`。

`K_N=P_N∩{F≤0}` 可以是圆盘、圆环、多个区域或空集。不能从三条边的根序号猜出这些连通关系。

## 5. 完整平面分区，而非边根拼接

使用仓库已有 CGAL 代数曲线 arrangement 能力，先对全局 `F` 及球投影边界建立分解，再插入固定法向面的直线。代数后端的实际编译／链接可用性必须在实现第一步验证；示例源码存在不等于当前构建依赖已经满足，缺失依赖必须显式失败。

分区需要保留：

- 所有曲线分量、孤立点、交点、重根／重合弧和无界分支。
- 投影临界点、根的顺序、弧的邻接、每个区域的内环／外环和精确符号。
- 同一四次曲线在不同法向面中的共享身份，避免每面重新生成不一致轮廓。
- 法向边的规范端点顺序、根序号和隔离证据；与已有 `TruncationRootCertifier` 的分区逐项交叉检查。

计算使用的包围框从球投影域推出，只是隔离算法的界，不成为新的规则网格或源离散。完整分区必须有可重载的邻接／符号证据；仅有若干采样点或渲染轮廓不通过。

投影临界点 `F=F_v2=0` 不自动是几何奇异；只要其局部定义系统正则，就可以作为构造点。真正的曲面／球切触、分量诞生消失和无法处理的重合事件分别记录，不用一个笼统的“求根失败”吞掉。

## 6. 唯一闭合策略：球内正材料的共同投影构造

新路径不再尝试旧单环挤出，也不按结果选择凸包、体素或另一种封口。其连续参考对象明确为：

`S⁺={x : q(x)≥0, ||x||≤R}`。

记 `D={v : vᵀEᵀEv≤R²}`，在 `D` 内定义球的上下高度：

`h±(v)=±sqrt((R²−vᵀEᵀEv)/||u||²)`。

沿每条 `x=Ev+ut` 的射线，正材料区间严格按下表决定：

| 精确条件 | 材料区间 | 下边界 | 上边界 |
|---|---|---|---|
| `h>h+` | 空 | 无 | 无 |
| `h−≤h≤h+` | `[h,h+]` | 抛物面片 | 上球面 |
| `h<h−` | `[h−,h+]` | 下球面 | 上球面 |

等号位置作为公共边界分层处理，不能重复产生零面积面。除 `F=0` 外，分区必须加入 `h=0` 和 `∂D`，以区分上／下球交支及整个射线都为材料的区域。圆环中间的孔不能直接丢弃：那里可能是最后一行的完整球内材料。

所有活跃区域共用一个带孔、可多分量的二维有限三角复形，再按标签提升上下边界。相邻区域共享同一组顶点、边和对角线身份：cut/full 边界上的曲面与下球盖共用点，cut/empty 边界上的曲面与上球盖共用点，赤道上上下球盖共用点。曲面侧绕向对应 `q≥0` 的外法向；球面侧绕向朝球外。不能靠每个粗三角形与解析梯度的点积独立翻面而破坏共享边绕向。

同一个已构造载体可以生成正负两侧，用于检查并集、正体积交集和方向；二者必须共享界面和球盖离散。其并集应为这个实际多面体球壳表示，不声称它精确等于解析球，也不要求两个独立重新网格化的 `q`／`−q` 自动产生同一个分区。

### 6.1 有限多边形化合同

精确曲线不是三角网格。每条弧先分为可认证的单调段，在隔离区域内按确定性的递归二分规则增加点。分割位置用端点／临界点坐标的固定有理比例定义，保存所在代数分支；不能取根隔离区间的中点当作曲线上永远不动的点。

每个曲线段必须同时证明：弦与弧在分配的隔离区域内具有相同端点连接和区域邻接；弦不穿过不相关边；全部弦组成的复形保留分量数、孔洞和符号区域。误差上界由区间／代数包围提供，不由有限采样最大值替代。

法向三角形内部的闭环必须获得新增轮廓点。所有相邻面消费同一公共边离散表；不得各自按坐标容差焊接。多环三角化使用精确方向判定、固定排序和确定性 tie-break；不以面积最大的环代替全部区域。

隐藏圆盘或球投影盘仅用轮廓点时，上下提升可能完全重合。为每个非空活跃二维区域添加**可微、具有严格正厚度见证的内部点**，并在必要的内部公共边添加同类点；使用区域分解中相邻事件坐标和弧高度的有理重心组合，保存其依赖表达式，不使用随迭代任意跳动的“随便找一个内部点”。

允许真正材料外边界上的厚度为零；不允许活跃载体三角形内部、或本应处于材料内部的边整段为零厚度。正厚度及平面复形合法性必须对整个单元认证，不只检查顶点的非严格次序。新增点与同一三角剖分被上下两层共同使用。

### 6.2 封口必须避开整个设计域

球面顶点在 `R` 上，不能推出其弦三角形也在设计域外。独立检查每一个实际封口三角形：

- 优先使用三角形到球心的精确最小距离，下界严格大于设计域最大半径上界加既定余量。
- 保守径向证书不足时，使用现有精确三角形／完整设计域相交及距离查询；不是仅测试顶点。
- 有限精度坐标转换的误差计入界；实际用于 Boolean 的表示必须重新检查。
- 同时认证正侧填充、设计域覆盖及完整分区；单纯“封口不相交”不足以证明选中了正确材料侧。

分区／封口细分规则和上限在运行前固定，并进入新映射身份；只允许按这些规则细分，不能扩大原球半径或法向球层级。细分上限内仍无法证明就返回具体见证，不启动 Newton 消耗预算。

### 6.3 赤道与必要切触

在 `∂D` 上，上下球面合并。若同时 `h=0`，`F=0` 与投影圆边界有结构性切触；不能因此把所有穿越赤道的合法输入都拒绝。

赤道点使用球面方程、`uᵀx=0` 和相应弧／采样约束的显式局部定义，不对 `sqrt(0)` 直接求导。共享点只保留一个身份。若相应三维定义系统正则，几何与导数可以通过；真正不正则或拓扑变更才返回相应事件状态。

## 7. 数值表示与误差不是一个概念

依次记录三个不同对象：

1. 精确有理系数及代数分区：用于证明完整性、分支和拓扑。
2. 按本设计采样规则生成的实数代数顶点、有限分片平面源：用于定义被微分的离散映射。
3. 实际传给 Cherchi 的有界 binary64 源顶点及其精确有理解释、最终精确材料：用于运行、独立积分和封存。

不把有理根隔离证据误写成所有曲面点都有有理坐标；不把有限浮点舍入函数说成处处具有本设计的实数导数。解析微分对应第二层，实际第三层与之的误差及完整映射差分必须通过现有门槛，否则导数不可用。

新 profile 的精度参数独立于既定科学验收阈值。初始方法验证建议锁定：弧／面表示偏差不超过输入固定尺度 `L` 的 `2^-20`，代数点转浮点的认证误差不超过 `2^-44 L`；局部隔离和封口距离可以要求更小的误差，不可放宽这两个上界。`L` 从输入坐标／设计域预先确定，不随结果变化。两者只是实施参数，不保证最终材料达到 `1e-6`，不冒称论文原值。

实现计划须在首次运行前冻结这些值及细分、代数位数、对象数上限，并写入配置。超限为 `RESOURCE_LIMIT`，提高精度或改变规则是新映射／新运行，不能只加密展示出口后升级旧求解结果。

## 8. 顶点运动、参数基与事件

### 8.1 真实秩二参数

用非奇异 `2×2` 主块建立局部 Schur 图：

`A=[[C,w],[wᵀ,wᵀC⁻¹w]]`。

`C` 三项、`w` 两项、`b` 三项及 `c` 一项，共九个齐次参数；固定一个非零齐次尺度后为八个参数。归一化映射的导数提供真实 `10×8` 系数基。若重用现有正交基，必须显式计算并保存与这八个坐标之间的转换。

差分沿此精确秩二图生成输入，再通过同一源工厂；禁止直接 `q±hB` 后浮点归一化，把偏离秩二的点当作定类型差分。需要微分 `u,E,h`、所选事件点与内点表达式，不能冻结移动坐标框架。

重复的两个非零特征值不会使这个图失效；主块变奇异、主元／齐次尺度分支切换才触发图事件。通用球面测地线离开秩二时仍走相应满秩处理，不能强制投影回来以伪装论文通用 Newton。

### 8.2 新顶点必须拥有定义方程

来源类别至少区分：原法向顶点、规范法向边根、曲线临界点、弧内分割点、区域内部点、球面／赤道点以及共享界面点。保存依赖 ID、根序号、隔离区间、定义方程及正则性证据。

例如法向边球交点，固定 `m=n0×n1`，满足：

`q(x)=0`，`xᵀx=R²`，`mᵀ(2Ax+b)=0`。

其微分为：

`[Gᵀ; 2xᵀ; 2mᵀA] dx = −[xᵀdA x+dbᵀx+dc; 0; mᵀ(2dA x+db)]`。

只有实际选中的根分支及非奇异方程才适用。不能恢复为“端点异号、只取一个根”的旧假设。内部临界点、采样点和封口点使用各自方程／依赖表达式及链式法则；不得统一将其速度置零。

### 8.3 缓存与重新线性化

科学身份包含：源系数、坐标、固定法向网格、原半径、构造 profile、精度配置、图主元、代数分支、有限多边形化／三角化连接、封口标签、实际后端及输出。

把几何坐标摘要与组合分支摘要分开；隔离区间细化不能任意改根身份，但其证明记录必须可重载。图、根邻接、封口、采样深度或三角剖分变化均失效旧 Jacobian。每个试探先构造自己的几何，只有当前分支有效时才产生当前导数；不可微事件按既有拒绝／回溯／重启规则记录。

差分只对同一合法分支比较，且至少三个步长。分支越界不混入误差平均值，也不能删除后宣称所有方向通过。一般 Eq.14 入口继续拒绝这个低维 Jacobian；定类型调用通过不关闭跨类型／通用优化要求。

| `QuadricTriangulation` | 增加版本化来源附件：点／弧／面 ID、区域标签、闭合／误差证据和分支摘要 | `closedBoundary`、`faceIsCap` 仍是实际材料入口；旧元数据数组不冒充新完整来源 |
| `QuadricStratumSourceMotion` | 读取上述附件，输出现有 `coefficientBasis`、`vertexVelocity` | 保留 `10×8`、`3×8` 真实维度，不复制到全维结构 |
| `QuadricMomentEvaluation` 及现有离散微分入口 | 值、来源、材料与导数消费同一次构造／Boolean；源微分接受同一个构造对象，核验输入／计划／源摘要 | 复用已有任意数量 `3×8` 顶点速度的传递内核；`stratumDifferential` 与全维 `derivativeDefined` 保持现有区分 |
| 现有精确材料与 `SealedSpinArtifact` | 增加来源附件引用，重载真实材料再积分 | 不建立平行封存系统；壁厚等未知项仍未知 |

新数学实现应分离为内部源准备、曲线分区、有限网格和运动四个小单元，不继续把全部内容塞进已有大 triangulator。对外仍只有现有求值链，不新增绕过材料审计的演示入口。

## 10. 失败分类与通过边界

| 状态 | 含义与行为 |
|---|---|
| `INPUT_IDENTITY_MISMATCH` | 系数／视图／配置／后端失配，拒绝结果复用 |
| `EXACT_STRATUM_MISMATCH` | 实际权威多项式不属本路径，不能近似投影 |
| `ARRANGEMENT_UNRESOLVED` | 无法认证完整曲线分区，输出未知而非空域 |
| `SOURCE_TOPOLOGY_INVALID` | 非流形、错误绕向、退化或自交，有定位见证 |
| `CAP_DOMAIN_INTERFERENCE` | 封口越界或覆盖证据失败，不能继续 Boolean 求解 |
| `FLOAT_DERIVATION_INVALID` | 浮点源无法保持已认证拓扑／分区／隔离，保留权威与派生物区别 |
| `DERIVATIVE_BRANCH_EVENT` | 当前映射不可微或分支失效，不复用旧 Jacobian |
| `DERIVATIVE_UNAVAILABLE` | 无法覆盖声明方向，几何成功仍可独立保存 |
| `RESOURCE_LIMIT` | 明确哪个预算耗尽，保留可重载证据 |

几何、导数、实际材料和求解通过分别记录。全部反例被“正确拒绝”不能构成本功能完成；必须实际通过下列正向集合。局部图不适用时允许换一个已定义图并重新建立当前导数，但必须记录身份；不能偷偷切换离散 profile。

## 11. 验收矩阵

### 11.1 解析与结构测试

共同二维测试三角形 `(-4,-4),(4,-4),(0,6)`，`R=3/2`。三边到原点的距离平方 `16,144/29,144/29` 均大于 `R²`，用于证明边上没有截断根也可有内部区域；这是方法夹具，不是作者案例。

| 输入 | 必须实际恢复的结果 |
|---|---|
| `z=x²+y²` | 隐藏圆盘、完整正厚度材料，不是空集或零厚度三角片 |
| `z=x²+y²−2` | 隐藏圆环，边界半径平方 `(3±sqrt(2))/2`，孔中 full-ray 材料及下球盖 |
| `z=x²−y²+2` | 两个分离的球内曲面区域，正确连接各自封口 |
| 圆环直径 | 四根顺序与二维连通一致，不任意两两配对 |
| 反向共享法向边 | 唯一顶点 ID、相反局部次序、无裂缝 |
| 坐标置换／有理刚性变换／正系数缩放 | 对应几何、质量矩和来源语义一致；正缩放不产生源运动 |
| 相等非零曲率 | 不依赖任意特征向量而改变结果 |
| 同载体的正负材料侧 | 正体积交为空，并集为同一实际球内多面体，质量矩相加一致 |
| 赤道穿越 | 结构性投影切触正确处理，无 `sqrt(0)` 导数 |
| 真切触／分量合并／奇异截断 | 事件与不可用导数明确，不能误授予平滑分支 |
| 球盖顶点都在球外、三角形却进入设计域 | 必须拒绝，或按固定规则细分后重新认证 |
| 漏环、漏内点、错误绕向、来源错绑 | 反向测试必须拒绝 |

切触夹具保留 `z=0.75(x²+y²), R=1.25, x=1`；奇异截断保留 `z=x²+y²−1.25, R=1`，其 `F=(s−0.75)²`。后者不能当作普通二维曲面分区和光滑导数通过；其实际材料状态另行判定。

### 11.2 原八冻结状态

锁定 ID `{0,1,2,18,56,57,58,59}`、实际 level-2 法向网格、原 `R=4`、原设计域及 native 系数。沿用已有边证书，不重跑无关 Newton。

每个状态必须获得完整、可重载且合法的源网格与正侧封口，或者具体未通过证据。出现未通过时保留这个验收项，不能把本功能宣布完成。对成功状态两个独立进程比较材料前源网格、组合事件与来源摘要；时间不进入科学摘要。

### 11.3 导数与实际材料

- 源顶点与实际 Cherchi 材料：全部八个有效基方向、至少三个步长，误差 `≤1e-6`；近零导数用绝对检查，记录舍入噪声及分支边界。
- 实际输入、面来源、交点来源、输出精确材料必须绑定；检查器从保存的几何重新积分，不接收手填通过。
- 非退化解析多面体质量矩门槛 `≤1e-10`；最终材料质量矩及约束 `≤1e-6`。
- 保留 CGAL 独立实体／质量矩对照；同源质量矩接近不证明实体相等。
- 只有上述通过后才安排适用的受控完整调用，记录真实更新及最终材料；本设计不把定类型调用标成通用 Newton 成功。
- 原通用 Faster `α=t_max=0.5`、raw residual `≤1e-12`、每次最多 60 次求值不变；种子 0、1、每种子最多八次尝试的开发约束不变。

## 12. 实施拆分、预算与退出规则

详细实现计划在本书面设计审阅后制定，并细化现有关键路径，而不是另立总体目标。依赖顺序固定：

1. 工厂／精确图合同与解析反例；验证既有代数后端可用。
2. 完整 arrangement、共享来源与有界多边形化。
3. 共同投影闭合、严格厚度、封口及实际浮点源检查。
4. 新顶点运动、真实定类型参数基、实际 Cherchi 材料差分。
5. 八状态重复、受影响集成和当前支持范围审计。

几何正向集合未通过，不进入随机求解。一个失败状态完成定向诊断后，只为确证修复、新的明确假设或独立重复再次运行。不得通过加预算、换输入、减 handles／法向层级或抹去未通过项获得结论。

编译最多四并发；大型作业顺序；单作业 24 GiB、swap 0、60 分钟；数值库单线程。首次代数构造使用更小的登记诊断预算，实测后才决定整个八状态批次；不预先承诺全部在该预算内可完成。保留存储门槛，运行中可用空间低于 20 GiB 安全停止。

### 本设计的主要风险及处理

- 代数 arrangement 成本可能高：全局曲线只分析一次，复用面查询；超限明确退出，不换规则网格。
- 代数拓扑正确而有限网格不合法：必须保留有限多边形化和闭合的独立门，不能只依赖 CGAL 成功返回。
- 高精度舍入破坏秩或几何：单一权威源、严格绑定和派生物检查；不能“近似相同”即授予通过。
- 分支变化频繁：分别验收几何和局部导数，记录实际事件；不承诺跨类型通用光滑性。
- 即使本设计全部实现，也只关闭明确的完整秩二构造／定类型材料链，不自动关闭通用 Newton、CAD 精度、原论文实验或整个 Faster 的最终完成门。
