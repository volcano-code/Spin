# 三维 Spin-It Faster 完整收尾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: 使用 superpowers:executing-plans，在本聊天逐任务实施；不自动恢复案例、不提交、不合并。最终独立审查单独安排。

**Goal:** 在登记的曲面支持范围及三规模十种子基准上，分别完成核心正确性、正式工程链路与性能验收。

**Architecture:** 保留正式进程内 Cherchi、原生球面 Newton、同次材料附件与独立终态重载。先核验已有性能候选，再形成可从源码重建的统一版本；以该版本执行全部验收，不拼接不同版本的局部通过。

**Tech Stack:** C++、Python、Cherchi、CGAL 显式对照、GMP 精确积分及谓词、独立有理四面体积分。

**Spec:** 用户批准的“先正式 Cherchi，再修复几何”规划；基线证据见 docs/three-dimensional-faster-evidence-closeout-v2-progress.md。本文替代旧计划中已完成的待办，不改变数值门槛。

## Global Constraints

- 心形、面条完整案例及其自动跟踪保持暂停，仅消费保存失败状态；报告提交后不自动恢复。
- 不增加浮力、制造、视频、质量最小化、学习加速；2014 五目标另行验收。
- Cherchi 为正式验收后端；CGAL 为显式对照，不失败后静默切换。
- 大型构建及实验串行；单作业 24 GiB、swap 0、60 分钟；编译最多四并发、数值库单线程。
- 磁盘启动至少 100 GiB、运行至少 20 GiB；保存历史与用户修改，不覆盖旧模块、不提交、不合并、不删除。
- level 2；种子 0–9；每种子最多八次尝试、每次 60 次求值；alpha=t_max=0.5；raw residual≤1e-12；保持正乘子筛选。
- 解析质量矩误差≤1e-10；适用光滑方向三尺度导数误差≤1e-6；终态独立质量矩及约束误差≤1e-6。
- 不答案初始化、不替换失败种子、不拼接超时续跑；无修复或新诊断不重复相同失败长跑。

## Review Focus

- 精确过滤器不确定、下溢或近共面：回到精确谓词，不使用容差代替真实判定。
- 多壳或空腔：不能进入仅单外向闭合壳的快路径；终态区域检查仍完整。
- 候选 overlay 与标准源码构建不一致：必须证明实际链接及加载来源，不能只看最终 .so 摘要。
- 真实构造分支变化：不得冒充等价重三角化或光滑差分证据。
- 日志检查点与材料目录同步失配：完成事件不能引用未持久化的材料；无更新或篡改必须拒绝。
