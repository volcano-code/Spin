# Spin-It G7 Post-Solve Diagnostic Replay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure the work after the immutable G7 pass-20 SLQP trace without resuming or advancing the optimizer, and determine whether transition or evidence-sealing work plausibly consumed the remaining wall time.

**Architecture:** Add a separately named diagnostic-only native replay that verifies the committed stage-19 checkpoint, reads and validates the complete pass-20 trace, then executes only the post-solve level accounting, split/merge, result hashing, checkpoint capture/encoding, and isolated diagnostic write operations under phase timers. A small synthetic regression must show parity with the normal one-pass result while proving no SLQP solve is invoked; a Python controller binds the real replay outputs to immutable G7 evidence and writes a supplemental report.

**Tech Stack:** Existing C++17 Spin-It source adaptive solver/checkpoint codec, pybind11 native extension, Python 3.13 supervisor utilities, pytest/CTest, SHA-256 evidence manifests.

**Spec:** User-approved strict reproduction plan, Stage 1 post-SLQP diagnostic replay and Stage 2 evidence-based-fix gate; source evidence is `build/spin2014-g7-linear-candidate-20260919/RUN_REPORT.md`.
