# Spin-It 2014 Reproduction Implementation Plan

**Goal:** Add an independent, auditable reproduction of the 2014 Spin-It
hollowing method without changing the completed Spin-It Faster solver.

**Source contract:** Equations (2)--(8) and Sections 5--7 of the paper.  A
continuous variable `beta=1` denotes void and `beta=0` retained material.
The printable result is binary; a relaxed field is diagnostic only.

## Milestone A: adaptive hollowing core

1. Add the opt-in `MAKE_IT_STAND_BUILD_SPIN_IT_2014` build flag.  Compile the
   raw-moment objective shared by both Spin-It implementations whenever either
   implementation is enabled; keep CGAL exclusive to Faster.
2. Introduce `spin2014::AdaptiveVoxelDomain` over an immutable finest-level
   `voxel::VoxelDomain`.  Octree leaves store integer dyadic bounds and exact
   sums of the finest occupied cuboids' ten raw moments.  Test conservation,
   deterministic ordering, split, merge, and face-neighbor symmetry first.
3. Introduce `AdaptiveFillFunctional`.  It evaluates
   `s = s_solid - sum(beta_k s_k)`, the paper objective/constraints, analytical
   fill gradients, and `0.5*gamma_L*beta^T L beta` using a symmetric graph
   Laplacian.  Test gradients with centered finite differences.
4. Implement a deterministic active-set sequential linear-quadratic solver.
   Each subproblem uses a limited-memory BFGS inverse-Hessian action, enforces
   the linearized equalities, clips the step at box constraints, and accepts a
   merit-function line search.  Record objective, equality norm, projected
   gradient, active-set size, step and line-search outcome per iteration.
5. Implement the paper split/merge loop: optimize, split fractional leaves,
   merge binary-equivalent sibling groups, terminate when every fractional
   leaf is at maximum resolution, then round deterministically and independently
   recompute physical moments and constraints.

## Milestone B: sealed products and examples

1. Extract retained-material and cavity boundaries from the binary finest grid.
   Bind input, adaptive trace, beta field, geometry and moment hashes in an
   immutable `SpinIt2014Artifact`.
2. Add C++ and Python APIs and an OpenGL result-view path with independent
   outer/material/cavity/CoM/spin-axis/principal-axis toggles.
3. Run deterministic analytic top, yo-yo and static fixtures twice, followed by
   reconstructed OBJ cases.  Compare raw moments and constraints against the
   Faster baseline where both solve the same mass-moment-only task.

## Milestone C: 2014 extensions

1. Add cage extraction from an octree level, BBW interpolation, the paper LBS
   scale/translation handle parameters, and joint fill/deformation derivatives.
   Add bi-Laplacian and surface displacement penalties.  Reject invalid mesh
   candidates before commit and mark silhouette-changing outputs explicitly.
2. Add `DualMaterialSpinSolver` with fixed boundary density and denser interior
   density.  Test the density-weighted ten moments and the one-material limit.
3. Seal paper-formula versus reconstructed parameters/assets in separate result
   ledgers.  A missing original model or weight remains explicitly blocked.

## Verification gates

- Every registered test runs and passes in 2014-only, Faster-only, combined,
  and both-disabled builds.
- Moment conservation and analytic gradients use relative tolerance `1e-9`;
  final independently recomputed equality residual uses at most `1e-6`.
- Repeated runs have identical leaf ordering, trace and output hashes.
- Continuous fields are never exported as printable geometry.
- Real-desktop OpenGL smoke tests occur only after non-GUI gates pass.
