# 三维 Spin-It Faster 有证据收尾 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking. 本文为待用户批准的新计划，不是完成报告。

**Goal:** 在登记支持范围内交付正式 Cherchi 三维核心，分别通过正确性、工程链路和性能验收。

**Architecture:** 复用现有 native 源面、原生 Newton、进程内 Cherchi 及封存链；只修证据指向的缺陷。保留同次材料附件，分离原始运行记录与排除具名时间字段的科学重复摘要。固定状态、小型闭环、规模基准逐级准入。

**Tech Stack:** C++20、Eigen、pybind11、固定版本 Cherchi/TBB、显式 CGAL 对照、Python、精确有理数积分。

**Spec:** 用户最后批准的“先正式 Cherchi，再修复几何”计划；原范围记录于 `docs/superpowers/plans/2026-10-13-three-dimensional-faster-core-ten-seed-closeout.md`。实际证据见 `docs/three-dimensional-faster-cherchi-first-progress-20261013.md`。本计划仅提出下述导数协议新增项，批准前不替代旧标准。

## Global Constraints

- 心形、面条完整案例及 automation 保持暂停；仅保存失败状态用于核心回归，验收后不自动恢复。
- 不增加浮力、制造、视频、质量最小化或学习加速；2014 五目标单独验收。
- 正式后端 Cherchi；CGAL 显式对照，失败不自动换后端。
- level 2；seed 0–9；每种子最多8次尝试、每次60次求值；alpha=tmax=0.5；raw residual <=1e-12；保留正乘子及有效敏感度检查。
- 解析质量矩 <=1e-10；生产导数目标误差 <=1e-6；终态独立质量矩及约束 <=1e-6。不得改生产 J 去拟合粗差分。
- 大型构建和实验串行，24GiB、swap0、60分钟；编译<=4，数值线程1；沿用100GiB启动/20GiB运行磁盘门。
- 不覆盖冻结模块、不提交、合并或删除；不修改运行中绑定依赖；无修复或新诊断不重跑同一失败长作业。
- 条件预算不是保证冻结输入必然收敛。30种子未全部通过时整体基准不通过；失败种子不得替换。

## Review Focus

1. 非二进制归一化和旋转/平移导致原实体丢失：物理 Boolean、精确仿射转换与分区必须保持一致（任务2）。
2. 高曲率光滑状态的粗五点误差被误作 J 错误，或反过来掩盖错误 J：独立判据、负例及旧失败保留（任务1）。
3. 缓存对象被修改、后端/来源改变或不可微试探沿用 J：缓存完整身份、附件不可变与明确拒绝（任务2、4）。
4. 零更新收敛、缺日志或末次拒绝试探被当作成功终态：实际接受记录和文件摘要绑定（任务2）。
5. 基准只算最后重启或把同实体细分当复杂造型：全种子完整成本、语义分区和独立科学重复（任务5、6）。
