# Spin-It 2014：零步长回退的定位与候选修正

本轮完成的是轨迹级定位和独立候选方向验证，**没有替换原生优化器，没有
重新求解成功的茶壶**。总状态仍为 `PARTIAL_BLOCKED`，输入仍为重建茶壶。

## 从统计线索到可重复的定位

研究对象是上一轮两次独立G7/O7、SLQP960实验的完整档案。新增
`experiments/teapot_spin2014/direction_replay.py`，逐条恢复实际L-BFGS历史、
活动成员重置、旧乘子下的secant差分及原生Schur方向。保留完整读取和档案
校验，不修改历史轨迹。NumPy小型SVD替代Eigen COD仅用于诊断，必须先检查
其重建步骤与记录步骤的一致性，不声称两种分解算法逐位相同。

全档案有1348个事件；1273个原生非回退已接受步骤可逐坐标比较。最大绝对
状态误差4.5630166e-14。末轮54次回退、全程64次回退，**均对应拟牛顿方向
最大盒约束步长为0**；没有一次L-BFGS初始缩放触及现有上下限。
这定位了回退的直接触发机制，不证明它是所有收敛缓慢的唯一原因。

当前原生实现先按单位度量的投影梯度决定活动集合，再用L-BFGS度量构造
方向。正定度量仍可让某个已释放的边界坐标指向盒外，于是整体步长被截成0，
随后退回一阶方向并清空历史。并非只有“非下降方向”才会触发这条路径。

解析回归用一次BFGS更新构造
H=[[1,2],[2,9]]，g=[-1,1]、x=[0,0.5]。拟牛顿方向[-1,-7]的方向导数为负，
但x0已在下界，合法步长为0；身份度量方向则可向盒内移动。

## 未接入native的候选修正

在同一SPD拟牛顿度量下处理切锥方向QP：活动面加入与释放都使用该QP的方向
与乘子，保留等式约束。直接BFGS Hessian递推独立核验stationarity，而非仅
调用inverse递推自证。内点的有限盒距离仍要由bound_step和之后的真实merit
线搜索处理，QP不是完整非线性优化器。

候选原型的限制明确为诊断默认值：至多256个边界面、4*面数+4轮工作集循环，
循环/预算/不准确线性求解返回QP_UNKNOWN，不授予不可行证书。它不是作者
公开的完整SLQP程序，也不构成原论文实现一致性的证明。

第一版候选在64个状态上虽满足数值QP容差，但固定面的约1e-17级浮点外向
残差仍使实际bound_step为0。该失败试验保留为`g7-tangent-probe-r1.json`。
修正后仅把工作集中数学上固定为0的方向坐标精确表示为0，再重新检查等式
和完整stationarity；不夹断自由坐标，不修改beta，不放宽优化/舍入验收线。

修正后的完整两份轨迹诊断一致：64/64候选方向均有正步长且方向导数为负。
最大线性化等式误差3.0196839e-14，最大QP stationarity为1.9920589e-15。
这是**历史状态上的局部方向探针**，没有实际执行非线性merit检查、接受这些
步骤或继续优化；不能由此宣称迭代数下降、level7收敛或二值验证通过。

## 测试与证据

按系统调试、先红后绿流程新增解析与负例测试，覆盖上下边界、错误面释放、
等式、未解决QP不冒充不可行、固定方向浮点残差、非法输入、冻结旧乘子的
secant，以及完整回放的历史/状态失配和缺失档案尾部。

独立审查发现的非法输入与NumPy广播误报均有失败回归后修正。逐条验证
state、gradient、Jacobian、constraints、active、lambda尺寸及有限性，禁止
二维预测与一维错误终态被广播成“完全一致”。

最终13项新测试与20项既有流式/回放测试合计33项实际通过，无失败或跳过；
记录见`final-tests-v2.log`、`final-tests.xml`。pytest仍有既有asyncio配置弃用
警告。这里不是全项目或原论文发布验收，本轮未改动原生求解器源码。

结果根目录为`build/spin2014-direction-audit-20260914`。最终运行配方
`run_bound_audit.py`在执行前后核验原实验来源/输出及本轮诊断代码，完整结果
为`final-bound-r1.json`、`final-bound-r2.json`；时间和资源不进入诊断结果的
确定性比较。所有旧版失败、红/绿日志保留，没有commit/tag/发布或主目录覆盖。
