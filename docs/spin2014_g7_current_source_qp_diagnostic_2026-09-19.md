# Spin-It 2014 G7：当前源码固定 QP 回放诊断（2026-09-19）

## 范围与结论

本诊断只对 G7 历史完整轨迹中两个工作面最大的已检查 QP 做固定输入回放；没有启动、恢复或推进非线性优化器，也没有验证二值化、最终材料几何、仿真或论文复现。

旧的 G7 固定 QP 计时结果绑定的是不同的 QP 与轨迹存储源码，不能代表当前源码。本批次用当前源码重新构建回放器、各阶段各重复两次、独立重算 QP KKT，并以临时计时插桩进行对照。结论如下：

1. 两个当前源码回放均得到 `BOX_QP_FIRST_ORDER_CHECKED`，活动集和乘子与历史记录相同。
2. 方向向量与历史记录不逐位相同，最大分量差分别为 `1.1535911115245767e-16` 和 `1.8401079271423981e-15`。因此历史记录的完整序列化逐位比较失败；这不能被报告成历史结果与当前源码逐位一致，也不足以单独说明算法错误。
3. 每个阶段相同输入的两次当前源码输出完全确定；独立盒约束 KKT 检查通过。
4. 当前这两个固定 QP 的最大计时段是 Schur 矩阵组装／缓存求解的合并范围，次要热点是候选方向与证书计算。尚未把 Schur 组装、缓存更新、快速解和回退分开，故本批次不做算法性能修复。
