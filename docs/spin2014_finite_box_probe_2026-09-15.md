范围：一次可行性探查，使用历史重建茶壶轨迹；不是原生求解器实现、全流程优化、

生产源码、原始模型、既有失败记录和未提交工作均保留。

## 比较的具体问题

沿用low-r1第三轮的94个填充变量和1个Givens角。
先固定选择952–959全部8个状态，即两个完整的后期四步模式，再求新QP。
每点使用原生在该点实际采用的BFGS历史，包含已执行的历史清空；
不另加“保留历史”处理，不改变gamma_L=0.0001、设计域或目标权重。

局部问题为：最小化 `g·d + dᵀBd/2`，满足 `A d = -c`，
以及所有填充变量的完整位移界 `-beta <= d_beta <= 1-beta`；角变量没有盒约束。
这与仅在当前边界建立切锥方向、随后按其他变量的边界截短整条方向不同。

探查采用本机SciPy1.15.3的SLSQP作为小型稠密参考求解器，500次迭代上限，
ftol=1e-14。QP目标缩放和等式行归一化由输入固定计算，原始未缩放残差另行核验。
利用独立的BVLS乘子恢复和残差计算，不把SLSQP的success字段直接当作正确性证明。
检查B正定、等式、盒边界、驻点、乘子符号和互补性，局部KKT门为1e-9。
该局部工程门与完整优化的驻点门1e-7、二值约束门1e-6不是同一项验收。

## 原始目标的独立核对

根据保存的外表面矩和实际单元矩重建保留材料矩。
用整数网格盒的面相交关系重建均匀Laplacian，不调用原生邻接构建。
重建TOP_INERTIA_ONLY的Givens形式及gamma_L正则项。
第三轮全部961条状态核对目标与约束；所选8点的全部95个坐标做复步长导数核对。

- 目标值最大差：7.10543e-15。
- 约束值最大差：1.64562e-17。
- 目标梯度最大差：1.33574e-16。
- 约束Jacobian最大差：8.32667e-17。

这些检查证明本局部重建与保存的原生求值一致，不代替原论文参数来源证据。
检查过3个手算小型QP：非对角SPD有限盒解、带等式解、上界解。
它们是诊断夹具，不计入论文模型完成数，也不是新注册的核心测试。
