# Spin-It 2014：低权重驻点停滞与方向回放修复

本轮完成低权重第三轮的历史轨迹诊断，并修复Python方向检查器遗漏切锥方向的错误。
原生优化器、模型、参数、迭代上限和验收阈值均未修改；没有执行新的优化，
也没有把未知连续解转为成功材料。不是原论文案例完成或物理验证。

工作目录：`/data/xvxinyao/moment-guided-spin-v1/code/make-it-balance-paper-sim`。
证据目录：`build/spin2014-low-stationarity-20260915`。
历史输入：上一轮gamma研究的low-r1、low-r2，gamma_L=0.0001，重建G6/O6茶壶。

## 1. 先修复诊断错误，不改优化轨迹

旧direction_replay.py始终用普通拟牛顿方向预测下一状态。但原生求解器的
METRIC_TANGENT_RESCUE_V1在零边界步长时可能选择另一条、已记录的切锥QP方向。
低权重第三轮实际接受了241次这种方向；旧回放因此给出约0.064的虚假状态差异，
并正确地拒绝继续授予诊断通过。原始失败日志保留。

修复后的检查器识别实际接受的方向分支，但不只相信记录中的checked=true：
用记录的梯度、约束、历史secant对，独立重建直接BFGS Hessian，重算该方向的
等式残差、驻点残差、边界方向和乘子符号；检查工作集、维度、有限值、接受状态
冲突及边界步长。独立复审后补齐初始/末次工作集的Schur满秩检查、试探数量、
实际接受试探及末次CHECKED记录和残差一致性。秩检查使用独立SVD及1e-12相对门，
不声称与原生Eigen COD逐位相同。仍然核对完整归档，以及实际下一状态。
这只是局部QP、所选方向及状态更新的核验，不是重新检查原始目标导数、
QP内部每个中间工作集的选择过程或全局极小值。

两份历史归档均完整读取、逐条比较并重放，结果一致。每份覆盖1205个接受更新。
第三轮960个接受更新最大状态回放误差4.71845e-15，241次切锥方向的最大独立
KKT误差3.36268e-14；全部三轮最大状态误差7.13735e-13，低于既有1e-9回放门。
普通拟牛顿方向仍用NumPy重算；所选切锥方向用独立Hessian证书核验。

| 盒约束残差 | 0 |
| 驻点残差 | 1.4758433e-4 |
| 乘子符号残差 | 0 |

驻点门保持1e-7，因此仍为MAXIMUM_ITERATIONS / RELAXATION_UNKNOWN。

## 3. 观察到的是边界往返和慢下降，不是线搜索耗尽

第三轮记录中：

- 960个曲率对全部接受，0个拒绝；L-BFGS初始尺度没有触发上下限截断。
- 0次目标试探拒绝、0次非法目标求值、0次恢复尝试、0次一阶fallback。
- 478条ACTIVE_MEMBERSHIP_CHANGED重置记录（包括末次状态）；加初始新轮重置共479条。
- 实际更新所用历史长度最多5，478个更新使用空历史；上限配置仍为8。
- 变量31、59的活动身份分别变化474、476次，支配后期变化。

后期可见重复四步结构，但不是状态逐位相同的闭合循环：目标仍严格下降。
例如第956–960条状态对应：

| 状态序号 | beta31 | beta59 | 下一步所用历史长度 | 接受步长 |
|---|---:|---:|---:|---:|
| 956 | 0 | 1 | 0 | 1 |
| 957 | 0 | 0.9999987253 | 1 | 4.01643e-5 |
| 958 | 0 | 1 | 2，切锥方向 | 2.65135e-5 |
| 959 | 2.91005e-8 | 1 | 0 | 0.0157632 |
| 960 | 0 | 1 | 终态，不更新 | — |

全部试探都在首个候选被接受，故这里的短步不是Armijo回溯造成，而是先由
maximumBoundStep限制。活动集按身份变化清空历史的规则执行正常，但这个
规则与边界往返共同出现，无法维持长的曲率历史。

同相位驻点残差在100、500、900、960次分别约1.73329e-4、1.59956e-4、
1.49059e-4、1.47584e-4。说明仍在缓慢进展，不能把超时/迭代上限解释为不可行，
也不能按这段曲线外推出增加固定次数一定成功。

## 4. 不把“保留历史”直接当作已验证修复

在952、955、956、959四个已观察状态上，额外计算了保留重置前历史的局部切锥QP。
四个局部QP均通过其等式和驻点检查，但全盒边界步长仍只有约
2.95e-6、7.90e-6、2.95e-6、7.90e-6。它们没有执行非线性目标求值或实际更新，
不属于新的优化轨迹，不能宣称改善、变差或可行材料。
这一结果至少不支持“只取消历史清空就足够”的直接修改。

更有针对性的下一项是，在保存的94变量问题上检查包含全部有限位移界
`-beta <= d <= 1-beta`的QP子问题，与当前“切锥方向+全盒步长截断”比较。
先用解析小型夹具验证工作集加入/释放、乘子符号及KKT，再做局部非线性merit对照；
只有通过后才考虑独立、显式命名的方向策略和两次完整重跑。
这尚未实现，也不能预先宣称为作者原始数值实现。现有论文profile不被覆盖。
