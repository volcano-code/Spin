# Spin-It 2014 原生 metric-tangent rescue

状态：原生改进已实现并验证；论文计算复现仍为PARTIAL_BLOCKED。
范围是 `IMPLEMENTATION_DEFAULT` 工程改进，不是作者原 SLQP 程序逐位复现。
本轮仅修改隔离工作树中的 Spin-It 2014，不提交、不覆盖主项目脏工作。

## 实现与算法边界

上轮轨迹重放发现：64次已接受的一阶回退之前，旧拟牛顿方向的盒约束步长为0。
新的显式 `METRIC_TANGENT_RESCUE_V1` 仅在这个条件成立、且等式可行时介入。
其子问题用 L-BFGS 的完整正定度量，独立的工作集加入向外的约束面、释放乘子
符号错误的约束面。固定方向分量置精确0后，重新检查等式及完整驻点残差。

- 使用已有逆 L-BFGS作用；驻点检查用独立的直接 BFGS秩二更新，不建立稠密n² Hessian。
- 设置工作面及迭代预算；秩亏、循环、预算耗尽或检查失败均返回 `QP_UNKNOWN`。
- 检查通过只是候选方向；仍需有限盒步长和实际非线性 merit 线搜索接受。
- 不可用或被拒绝的方向回到原有一阶回退；回退接受后才重置历史。
- 没有将该局部子问题状态解释成原问题可行、不可行、收敛或物理稳定证书。
- 默认策略及其序列化字节不变。cage和旧voxel入口显式拒绝此新策略，尚未扩展到它们。

新增来源绑定字段包括策略、预算和子问题容差；每次记录 QP的方向、乘子、工作集
变化、残差及 `checked / selected / accepted`。`trial_count` 指明旧
`objective_trials` 中属于 QP搜索的前缀长度，`fallback_attempted` 与原有
`used_first_order_fallback`（仅表示接受）分开。所有新字段进入轨迹摘要。

这只是旧方向被盒约束阻塞时的救援路径，不是所有迭代均采用完整工作集 QP 的
新 SLQP。该差别永久保留在 profile 中；不能把这次修正当作“完整论文算法已验证”。

### 从设计域估算完整G7容量

上述终态有3648个可细分的分数单元（level3/4/5/6分别4/14/272/3358个）。
不扣除空子单元时，下一步细分的上界为16354+7×3648=41890；实际下限由
24000容量失败确认。该界只对应下一次细分，不是后续全部步骤的容量界。

进一步检查源树实现：最细边界单元保留在固定材料中，设计域质量矩只由完整
内部立方体累加。全部设计域叶的几何体积和为0.8273735046386718；
最细立方体体积为(3/128)^3。逐叶体积除以该值与整数的最大偏差为
7.105427357601002e-14，整数和64264。因此可以用65536的容量覆盖这份
固定G7保守设计域的完全细化，**不需要改变分辨率，也不需要根据优化填充率
改变输入设计域**。该结论不适用于其他模型或level8/9，不是连续可行性证书。

据此另设 `g7-rescue-65536.json`，仍只改三项容量字段。为遵守案例批次上限，
后续运行还受本轮首个对照开始后3600秒的总截止时间约束；如耗尽，保留日志，
未完成重复不得计为确定性通过。

65536组首轮到达40206个叶节点（加Givens角共40207个变量），前七轮连续
求解均通过，第八轮达到960次迭代上限：等式残差4.8750054e-15，驻点残差
1.3554664e-6，后者仍未过1e-7。因此终态为 `RELAXATION_UNKNOWN`，不是

首轮总耗时788.17秒（求解367.19、导出293.09秒，其余包括完整重读/摘要核对）。
第二次运行同样正常结束于 `RELAXATION_UNKNOWN`，总耗时803.91秒（求解

## 独立方向重放与下一处瓶颈

`metric_replay.py` 是结果目录中的独立诊断脚本，不修改优化器。它使用此前
Python逆L-BFGS/直接BFGS实现，根据记录的梯度、Jacobian及曲率对重建方向；
逐项核验QP等式、驻点、活动面与乘子符号，并比较实际接受的下一状态。
它**不重新计算几何导数，也不代替论文、几何或物理验收**。恢复步骤不计入
这里的拟牛顿接受步比较数量。旧策略诊断程序保留，不强行用于新策略。

辅助检查器新增7项真实归档/解析测试，均通过；已通过失败测试修正有限输入
运算溢出导致NaN可能漏检、末条记录的QP检查遗漏、零步长/同时恢复却标记QP
接受的矛盾记录。独立复审已关闭这些意见，历史脚本与失败测试输出保留。

最终复审版重放定位第八轮：50次QP全部接受，0次一阶回退，0次初始逆Hessian缩放
截断；活动集变化触发116次曲率历史重置。采样驻点残差从第0步5.84e-3到
第900步2.19e-5、终态1.36e-6，期间有波动，目标值仍下降。这说明960预算
结束时仍在进步，不能直接称为“方向失效”或“问题不可行”，也不能仅凭重置次数
断言其是全部原因。

最终重放检查G6的2052个接受步、209个QP，最大状态误差3.6734504e-14；
G7完整容量组的3232个接受步、167个QP，最大状态误差4.5630166e-14。
第八轮960个接受步的最大状态误差7.4384943e-15，QP驻点残差最大
1.3096186e-14、等式残差最大7.7238903e-17。这些是给定已记录导数后的
方向一致性检查值，不能替代最终材料的质量矩与几何约束检查。

复审版诊断脚本SHA256：
`f3061bbed28e601c3be70d12bfe28966badc9dcff0d720b231a9a045464264e4`；
独立BFGS辅助实现SHA256：
`a99285badbab68c71998e341219a489a206ac690311a4f6f51db079633f0c005`。
原始输出为 `metric-replay-g6-reviewed.json` 和
`metric-replay-g7-65536-reviewed.json`。

下一重点应是：

1. 以65536容量和现有策略为固定基线，先做仅增加SLQP预算的单变量试验，
   不改容差、初值、目标、舍入或分辨率，明确记录为数值预算处理。
2. 再审查活动集变化时全量清空L-BFGS历史的必要性，若提出保留/投影历史，
   必须独立证明与测试曲率、切空间及约束合法性，保留当前策略作对照。
3. 连续求解通过后，才继续二值材料、精确几何封存和同一对象仿真。

真实level9、全部目标/联合形变/双材料案例、作者原始输入与完整论文数值对照
仍未由这一个重建茶壶实验完成。本轮无打印、无新的优化成功视频、无发布标签。
