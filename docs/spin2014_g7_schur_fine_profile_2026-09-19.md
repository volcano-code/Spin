# G7 固定 QP 的 Schur 细分计时补充（2026-09-19）

## 范围与结论

本报告只覆盖已封存 G7 阶段 18、19 中机械选出的两个固定 QP，各重复回放两次。它没有恢复或推进非线性优化器，也没有执行二值化、最终材料几何检查、仿真或论文原始案例。

细分计时没有发现缓存拒绝、矩阵变化重建、活动面释放重建或 COD 回退。两阶段都从一次冷启动开始，随后缓存因活动集增加而逐次扩展；所有被计时的快速解均通过现有残差和稳定性检查。缓存/Schur 工作是两个固定 QP 的显著成本，但历史阶段缺少内部计时，不能据此断言它主导整段 G7 阶段时间。

因此本批不修改求解器，不更改目标、活动集、容差、缓存校验或 COD 保护，不启动新的完整 G7 试跑。此前一次候选循环平铺优化已因在两次固定 QP 上分别慢 53.6% 和 61.9% 而撤回；这次诊断没有产生足以替代它的修复依据。

## 方法及证据绑定

- 输入为旧完整 G7 轨迹阶段 18 和 19；第 20 阶段仍不完整，未使用。
- 当前独立回放器与只读轨迹读取器均绑定当前源码。容量参数使用 8；误用 64 的两次阶段 19 调用因 `history after mismatch` 失败，保留为无效诊断调用，不计入正式重复。
- 每个固定 QP 在单线程、24 GiB 地址空间上限、180 秒硬超时下运行。计时器只累计到单独的 stderr 记录，不进入科学 JSON。
- 对照同源码未插桩基线时，仅剔除 `read_seconds` 和 `qp_seconds` 后，阶段 18、19 的科学 JSON 均逐字段相同；各阶段重复运行的终态科学摘要、剖析计数一致。
- 独立直接 BFGS KKT 检查通过：阶段 18 stationarity `9.76e-18`、equality `3.36e-17`；阶段 19 分别为 `3.47e-18`、`1.07e-16`。两者 box、face、dual、complementarity 残差均为 0。其含义仅为这两个固定 QP 的一阶条件验证。
- 临时插桩源码、编译缓存、编译 flags、link line、计时程序和四次运行均有快照及 SHA-256。插桩结束后，生产源码恢复到原 SHA：`SlqpTangentQp.cpp` `7e255294…`、`SchurFactorCache.h` `b553c2a8…`；未插桩回放器 SHA 仍为 `61323e31…`。profile 二进制 SHA 为 `48343738…`。
- `perf stat` 仍不可用（内核 `perf_event_paranoid=4`），未混用系统采样数据。
