# Spin-It 2014 显式角变量联合函数：本轮验收

实现提交：`ce733ac915f322d939e887f04dea40fc5e4a1f58`。工作目录 `/data/xvxinyao/make-it-balance-paper-sim`，分支 `spin-it-strict-computational-v2`。总体仍为 **PARTIAL_BLOCKED**。

## 已落实

新增原生 `evaluatePaper(beta, phi, handles)` 和联合状态入口，将填充率 β、显式 Givens 角 φ、全部自由手柄参数接入同一目标函数和约束导数链。五种目标分别计算；静态模式没有角变量。保留旧消去角变量接口，支持固定旋转和锁定手柄。

测试实际运行了完整 cage → 细网格 → FEM → BBW → 三线性插值 → 联合函数，保留全部26个手柄。旋转模式共107个变量，静态模式106个变量。没有手填权重或减少手柄作为求解失败后的替代路径。

接口和明确适用范围见 [函数说明](spin2014_cage_givens_functional.md)。本轮没有新增最终优化模型、物理仿真或原论文案例。

## 实际验证

| 检查 | 结果 |
|---|---|
| 测试驱动 | 基础函数与实际BBW链路均先因显式路径未实现而失败，之后通过 |
| 新增重点回归 | 2/2通过；覆盖五种目标、全部联合列、三种差分步长及非法输入 |
| 2014相关CTest | 30项通过；最后1项依赖契约测试中断，不能写为31/31 |
| 单独依赖检查 | 在已配置的exact-OFF目录继续构建并运行实际审计程序，退出0 |
| 独立积分与导数 | 五种目标全部通过；不调用项目积分或目标函数实现 |
| 重复性 | 两次实际BBW及联合导出逐字节一致 |
| 独立审查 | PASS / Approved，无须修正的问题 |

独立检查从输入顶点、面、实际权重、手柄状态重建LBS，以有向四面体积分计算十项质量矩，再构造惯量矩阵和Givens旋转，通过复步长检查所有变量导数。最大绝对差：

- 十项质量矩：`5.55e-17`；质量矩雅可比：`2.26e-17`。
- 目标及约束值：`7.22e-16`；联合导数：`4.79e-16`。
- 独立变形顶点：`3.33e-16`。

三步中央差分也呈预期误差下降。这些属于数值单元验证，不是优化器二次收敛或论文模型稳定性的证据。所有解析模型仍为 `SYNTHETIC_REGRESSION`。

旧完整质心惯量形式与论文显式形式的数值等价比较，必须同时满足相应质心约束和横向惯量对角化。测试发现原先仅检查对角化的比较前提不充分，因此保留原未满足约束的独立检查，另加满足质心约束的比较；没有放宽容差。两者在约束集之外的函数扩展和完整梯度不必相同。

## 依赖测试的副作用与后续要求

旧 `assert_spin_it_2014_dependency.cmake` 会删除并重建固定的 `build/spin-2014-disabled-contract`、`build/spin-2014-enabled-contract`。此次发现后停止其进程，仅完成已经生成目录中的后续构建和实际审计程序。被删除的是可重新构建的依赖缓存，旧缓存内容没有备份；没有删除源码、论文资产或实验结果。中断日志完整保留，不能把单独运行成功改写成原CTest通过。

再次进行广泛回归前，必须先把该测试改成每次运行独立、保留记录的临时构建目录，避免固定路径清理和任务间干扰。
